# THE WORDS ON THE SITE

# Each line is:   name = the words shown on the site
# Change only the words after the = sign. Keep the name before it exactly as it is.
# Lines starting with # are notes for you; the site ignores them.
# A word in curly brackets, like {poll} or {date}, is filled in by the site
# (the poll's name, a date, a number). You can move it or leave it out.
# After you save, the site updates in about two minutes. If a line is broken,
# the update stops, the old site stays up, and GitHub emails you.
